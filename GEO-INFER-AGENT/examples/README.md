# GEO-INFER-AGENT Examples

This directory contains working examples demonstrating intelligent agent capabilities.

## Available Examples

### Simple Agent Example (`simple_agent_example.py`)
Basic agent creation and initialization demonstration.

### Agent Examples (`agent_examples.py`)
Comprehensive agent examples including different agent types and behaviors.

### Active Inference Geospatial (`active_inference_geospatial.py`)
Active Inference agents applied to geospatial problems.

## Running Examples

```bash
cd GEO-INFER-AGENT
python examples/simple_agent_example.py
python examples/agent_examples.py
python examples/active_inference_geospatial.py
```

## Integration Examples

GEO-INFER-AGENT integrates with:
- **ACT**: Active Inference for agent decision-making
- **ANT**: Swarm intelligence coordination
- **SPACE**: Spatial agent behaviors
- **AI**: Machine learning for agent intelligence

See `GEO-INFER-EXAMPLES` for comprehensive cross-module integration examples.
