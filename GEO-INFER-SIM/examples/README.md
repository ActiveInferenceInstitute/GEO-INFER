# GEO-INFER-SIM Examples

This directory contains working examples demonstrating simulation capabilities.

## Available Examples

### Basic ABM (`basic_abm.py`)
Basic Agent-Based Model (ABM) simulation example.

## Running Examples

```bash
cd GEO-INFER-SIM
python examples/basic_abm.py
```

## Integration Examples

GEO-INFER-SIM integrates with:
- **SPACE**: Spatial simulation environments
- **TIME**: Temporal simulation dynamics
- **AI**: Intelligent agent behaviors
- **AGENT**: Agent-based modeling
- **ANT**: Swarm simulation

See `GEO-INFER-EXAMPLES` for comprehensive cross-module integration examples.
