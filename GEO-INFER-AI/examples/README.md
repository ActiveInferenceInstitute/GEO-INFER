# GEO-INFER-AI Examples

This directory contains working examples demonstrating machine learning and AI capabilities for geospatial data.

## Available Examples

### Basic Classification (`basic_classification.py`)
Image classification example using the ImageClassifier for geospatial image classification tasks.

### Spatial Prediction (`spatial_prediction.py`)
Spatial prediction example using SpatialPredictor for geospatial forecasting.

## Running Examples

```bash
cd GEO-INFER-AI
python examples/basic_classification.py
python examples/spatial_prediction.py
```

## Integration Examples

GEO-INFER-AI integrates with:
- **SPACE**: Spatial feature engineering and analysis
- **TIME**: Temporal prediction and forecasting
- **AG, HEALTH, ECON**: Domain-specific AI applications
- **DATA**: Data preprocessing and feature engineering

See `GEO-INFER-EXAMPLES` for comprehensive cross-module integration examples.
