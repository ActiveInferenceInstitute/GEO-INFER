# Agent: siberia

## Scope

Arctic and sub-Arctic geospatial analysis for Siberia — covering permafrost monitoring,
Arctic climate change, ecosystem dynamics, carbon cycling, infrastructure vulnerability,
and indigenous community adaptation.

## Capabilities

- **Permafrost Monitoring**: Active layer thickness, ground temperature trends, thaw settlement
- **Arctic Climate Assessment**: Temperature trend analysis, Arctic amplification, sea ice monitoring
- **Ecosystem Dynamics**: Taiga/tundra transitions, vegetation greenness, tree line shifts
- **Carbon Cycle**: Carbon stock quantification, methane emission tracking, flux analysis
- **Infrastructure Risk**: Permafrost-dependent infrastructure stability assessment
- **Indigenous Knowledge**: Community-based monitoring integration

## Data Sources

- Roshydromet (Russian Hydrometeorological Service)
- Russian Academy of Sciences monitoring networks
- ERA5 / NCEP reanalysis datasets
- MODIS NDVI/EVI satellite products
- International Arctic Science Committee (IASC)
- Arctic Council cooperation data
