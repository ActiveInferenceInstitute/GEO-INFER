# del_norte_dashboard

## Overview

Pre-generated dashboard output from the Del Norte County synthetic analysis pipeline.

## Components

| File | Description |
|------|-------------|
| `del_norte_intelligence_dashboard_*.html` | Full interactive Folium dashboard with multi-layer map |
| `del_norte_simple_dashboard_*.html` | Lightweight summary dashboard |
| `policy_report_*.json` | Structured policy analysis with community recommendations |

## Usage

Open the HTML files directly in a browser to inspect the dashboard layout and data
overlays. The JSON policy report can be loaded for programmatic analysis.

## Integration

These outputs are generated by the production `del_norte_county` analysis code using
synthetic data. They serve as baselines for visual regression and demonstration.
