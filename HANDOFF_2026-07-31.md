## Purpose

This handoff records the review, extension, refinement, validation, and
publication context for the current GEO-INFER worktree. It is intended to let
the next operator verify the result quickly, continue the open work without
reconstructing prior decisions, and avoid treating bounded or optional checks
as completed release evidence.

## Scope completed

- Repaired public API surfaces across SPACE, ACT, AGENT, SIM, DATA, and PLACE,
  including facade dispatch, REST error behavior, public exports, lifecycle
  state, message delivery, JSON serialization, and typed unsupported-operation
  errors.
- Standardized runtime H3 usage on native `h3-py` v4 APIs. The checkout runs
  H3 `4.5.0` and direct runtime contracts use `h3>=4.5.0,<5`. Polygon holes,
  multipolygons, antimeridian inputs, pentagon-safe rings, compaction, native
  boundaries, GeoJSON closure, and coordinate order have focused coverage.
- Removed fake/local H3 fallback behavior from DATA and hardened ACT, PLACE,
  and SPACE adapters around valid H3 cells and explicit geometry conversion.
- Made SPACE and PLACE visualization outputs deterministic and auditable:
  explicit inputs only, no synthetic observations, stable output names, input
  hashes, H3 version metadata, artifact checks, and accessibility checks.
- Replaced obsolete INTRA and EXAMPLES assessment behavior with discovery-based,
  schema-versioned, non-overwriting receipts that preserve historical reports.
- Converted the root TODO into an open-only acceptance ledger. Completed work
  is represented by code, tests, validators, and receipts rather than being
  mixed into active backlog entries.
- Synchronized recursive README/AGENTS signposts at every folder level and
  extended the generator so newly added signposts are checked before commit.
- Hardened selected ART, SPM, IOT, CLIMATE, ENERGY, AGENT, and SIM test/runtime
  contracts found during the broad review.
- Added an isolated AGENT asyncio test fixture so legacy unittest-style async
  tests remain warning-clean under Python 3.12+.

```bash

git fetch origin main
git status -sb
git rev-parse HEAD
```

`origin/main`. No credentials belong in this handoff or in the repository.
