# GEO-INFER-ACT Examples

This directory contains working examples demonstrating Active Inference capabilities in geospatial contexts.

## Available Examples

### Simple Model (`simple_model.py`)
Basic Active Inference model demonstration with categorical states and observations.

### Modern Active Inference (`modern_active_inference.py`)
Contemporary Active Inference implementation with belief updating and action selection.

### H3 Active Inference (`h3_active_inference.py`)
Active Inference integrated with H3 spatial indexing for geospatial applications.

### Urban Planning (`urban_planning.py`)
Active Inference applied to urban planning scenarios with spatial constraints.

### Ecological Model (`ecological_model.py`)
Ecological system modeling using Active Inference principles.

## Running Examples

```bash
cd GEO-INFER-ACT
python examples/simple_model.py
python examples/modern_active_inference.py
python examples/h3_active_inference.py
python examples/urban_planning.py
python examples/ecological_model.py
```

## Integration Examples

GEO-INFER-ACT integrates with:
- **SPACE**: Spatial Active Inference models
- **AGENT**: Active Inference agents
- **ANT**: Swarm intelligence with Active Inference
- **BAYES**: Bayesian belief updating

See `GEO-INFER-EXAMPLES` for comprehensive cross-module integration examples.
